# Implementation research (2026-11-27)

Use the product's existing stack and data driver. For a small new dashboard, Chart.js is the recommended default: framework-free, MIT, responsive and suitable for two daily trends. Registry metadata at research time was4.6.2; pin the chosen version and bundle locally with its license. Use category day labels to avoid an extra date library/adapter. Canvas needs accessible text/table values. Sources: [responsive charts](https://www.chartjs.org/docs/latest/configuration/responsive.html), [accessibility](https://www.chartjs.org/docs/latest/general/accessibility.html), [time-scale adapter requirement](https://www.chartjs.org/docs/latest/axes/cartesian/time.html), [MIT license](https://github.com/chartjs/Chart.js/blob/master/LICENSE.md).

Vega-Lite is credible for richer declarative analysis but requires Vega, Vega-Lite and Embed, unnecessary for the minimum two trends. [Official embed guide](https://vega.github.io/vega-lite/usage/embed.html). Do not force a library migration on an existing dashboard project.

For intermittent/costly product sources, aggregate SQLite avoids a separate database service. Open source SQLite with URI mode=ro; query_only is supplementary, not a role boundary. For PostgreSQL use restricted source credentials plus read-only transactions/timeouts. [Python SQLite URIs](https://docs.python.org/3/library/sqlite3.html#how-to-work-with-sqlite-uris), [SQLite query_only caveat](https://www.sqlite.org/pragma.html#pragma_query_only), [PostgreSQL client settings](https://www.postgresql.org/docs/current/runtime-config-client.html#GUC-DEFAULT-TRANSACTION-READ-ONLY).

Existing NED Preview already provides safe admission, listener capture and isolated HTTP/WS transport. Reuse these internally while partitioning dashboard state per project. Existing COM Dashboard navigation and Base/Muse design already exist. Hub's singleton advertisement needs negotiated multi-app support to retain working Preview concurrently; localhost-only publication cannot establish remote delivery.
