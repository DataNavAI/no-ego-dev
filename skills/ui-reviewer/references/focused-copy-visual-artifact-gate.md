# Focused copy and visual artifact gate

Use for an exact read-only verdict on a small UI revision with frozen copy, screenshots, annotations, and runnable source.

1. Read the governing product contract, UI brief, review index, and canonical guideline together.
2. Build a state matrix from every declared state and reconcile clean/annotated captures, runtime routes/controls, and source/generated strings.
3. Inspect the native-resolution contact sheet and every annotation. Verify markers point to intended controls without hiding required evidence.
4. Exercise the exact viewport and record overflow, relevant rectangles, fixed-navigation bounds, visible state IDs, control dimensions, and transitions. Keep probes outside the candidate.
5. Recompute WCAG contrast from actual source/computed colors, including primary actions, navigation, captions, status/error copy, and secondary controls.
6. Treat any declared but absent state as a handoff gap. Async actions require truthful pending, disabled duplicate input, and no success before confirmation.
7. Sweep copy for guarantees, unsupported certainty, and inconsistent no-action conditions.
8. Return only the caller's allowed verdict token and smallest material correction set. Omit safely reversible preferences when the caller asks for exact required changes.

Use `PASS` only when no material correction remains, `NEEDS ITERATION` for material copy/visual/state/accessibility defects, and `BLOCKED` when governing or inspectable evidence is absent. Do not invent alternate verdict vocabulary.
