# Archive-discovery fixture

This scenario isolates the ordinary daily-inventory boundary. A path segment named exactly `.archive` marks all descendants as historical storage regardless of where that segment appears below the skill root. Active packages may remain nested under category directories and must still be discovered recursively.

A passing response identifies `active-coder` and `active-designer` as active candidates, excludes both retired packages, and requires an explicit separate historical audit before archived bytes can become semantic inputs. Modification time, declared version, and package completeness do not override the archive boundary.
