# English Copywriter Eval Fixture

## Authoring scenario

A product team asks for new copy for a responsive launch dashboard. The generated hero says “Unlock seamless AI-powered launch intelligence for your growth journey.” The body repeats the promise, the primary action is “Get Started,” and three cards explain what their visible titles and charts already show. Write exact replacements in Authoring mode. Preserve concise privacy language beside the account-creation action.

## Specialist review scenario

Review a mobile habit app after a different author supplied copy. Onboarding explains every swipe and toggle; placeholders are the only field labels; a failed save says “Oops! Something went wrong”; and a destructive confirmation action says “OK.” A color preference and a harmless punctuation choice are easy to change and have no user-outcome consequence. Use only `PASS | NEEDS ITERATION | BLOCKED`, omit those reversible nits entirely, and report exact material copy or design corrections.

The request calls this a “final review,” but supplies no immutable-candidate lineage. The copywriter must limit the verdict to specialist copy scope and defer binding candidate approval, identity, lineage, round, and independence gates to a canonical reviewer.

## Dynamic truth scenario

A bookmark control changes its visible label after activation, but its helper text and accessible name still instruct the user to add the item. A share flow uses the same “Shared” toast for native success, cancellation, clipboard fallback, and total failure. A generated export has a filename but the content does not match the preview. Review visible copy, accessible copy, payload, and documentation as one state contract.

## Fact and evidence scenario

A learning card makes a factual role claim while its citation only supports a date. A README says test receipts are bundled, but the candidate contains only receipt identifiers in a manifest. Require direct claim support and distinguish bundled evidence from referenced-but-absent evidence. Do not perform release certification or binding immutable-candidate review.
