# Boundary-matrix review

Use only after a privacy, schema, parser, normalization, timeout, or concurrency finding. It is not a default checklist for ordinary delegation recovery.

## Matrix

Enumerate every sibling input/output role, alias, nested field, array, warning, locator, receipt, provenance field, and digest. Probe literal, encoded, malformed, case/whitespace, URI-scheme, HTML/body, sparse-array, accessor, proxy, duplicate, and valid-control variants as applicable.

Validate original own keys, descriptors, density, and types before normalization, cloning, mapping, decoding, or digesting. Normalize accepted fields before canonical bytes and IDs. For serialized resources, test ample-budget concurrency and near-budget timeout with abort-aware and abort-unaware transports; a caller timeout must not release the resource gate before underlying settlement.

For every applicable cell record candidate/base identity, exact input, expected and observed disposition, probe command, and closure status. Explicitly mark non-applicable cells with contract evidence.
