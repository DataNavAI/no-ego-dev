# Product Bootstrap Eval Data

This fixture describes a benchmark product pattern without requiring the agent to copy the benchmark literally.

## BENCHMARK.md summary

The benchmark is a lightweight service intake landing page. It has:

- a clear above-the-fold promise for busy service professionals,
- a short intake form that captures client details,
- a generated handoff summary that can be copied or sent,
- trust cues that make the next step feel low risk,
- simple responsive styling suitable for a quick public test.

For evals, adapt this pattern to independent dog walkers. Do not reuse benchmark brand names or copy; preserve the intake-to-handoff product pattern.
