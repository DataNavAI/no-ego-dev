# NEDCOM scoped UI guidelines
Scope: communicator only, separate from existing onboarding. Users browse a project's work, review artifacts and its app. Project identity precedes project content. Each section has one primary job. Plain labels: Project, Chat, Goals, Artifacts, Preview, Retry. Recovery explains user action without exceptions/sensitive paths.

Canonical [tokens](../../../docs/features/communicator/design/design-system.md) and [brief](../../../docs/features/communicator/design/ui-brief.md) govern implementation. Use native controls and header/navigation/main landmarks, one H1, skip link, visible focus, polite loading and transition error alerts. Keep project name visible and clear stale content on project changes. Keep loading/empty/error distinct. Wrap long names. Use one logical DOM order with mutually exclusive Chat/Preview mobile views; hidden workspace views are inert. Selecting the left workspace restores its last selected tab; hidden tab panels are inert. No remote resources or motion. Read-only UI must never imply editing or app startup. Use recoverable access/database/folder failure copy. No extra themes/components until a journey needs them.

Evidence required: desktop/mobile captures, 320px reflow, 200% text, keyboard and screen-reader order, contrast and focus. Reviewers inspect contracts read-only; author remediates. Browser support belongs to existing interface registry; this guideline does not claim untested support.

Benchmark [Lovable editor](https://docs.lovable.dev/features/projects/editor); detailed adaptation in [benchmark](../../../docs/features/communicator/design/lovable-benchmark.md). Preserve Antigravity-derived message rendering. Preview remains a truthful local availability surface with explicit new-tab Open app, without embedding or automatic startup.


## Left tab workspace revision (current governing layout)
The latest user direction supersedes the right inspector. UI-AC-14: desktop has one 360px left pane (320px intermediate), with Chat, Goals, Artifacts tabs, and a flexible Preview main area. Remove all right-pane toggles and close controls. UI-AC-15: tabs select one preserved panel; Goals is the visible replacement for Goal & Tasks. Chat remains the same NED Chat DOM/session. Arrow/Home/End navigation, selected state and inert hidden panels are required. On mobile Preview is initial and the toolbar switches Preview versus the left pane, restoring its selected tab. Project tabs stay selectable without a project and explain selection. Preserve current composer and message controls, truthful data availability and new-tab Preview behavior. Verify TC-006 controller transitions and desktop/mobile rendered captures.
