NED V1 · Telegram

Connect a new disposable bot

Do not reuse an existing production bot. Telegram requires you to create a bot through its official @BotFather; NED cannot accept BotFather legal or ownership actions for you.

Create the bot

  1. Open BotFather.
  2. Send /newbot.
  3. Choose a display name.
  4. Choose a unique username ending in bot.
  5. Copy the token. Return to the NED terminal prompt: Paste the Telegram bot token (input hidden):

NED calls Telegram getMe in-process, redacts provider-mandated token-in-path URLs, and displays only the verified username. Invalid or revoked tokens stop before Daytona provisioning.

Start and approve the owner

  1. Open the exact verified link printed by NED.
  2. Tap Start.
  3. Send hello.
  4. If Hermes sends an 8-character pairing code, return to the terminal and run ned pair <code>.
  5. Return to the bot and send hello again.

How the connection works

The pinned Hermes Telegram adapter uses long polling by default and deletes any stale webhook before polling. NED does not configure webhook mode. Direct messages use Hermes owner pairing unless an owner has already been approved. ned repair restarts the exact saved Sandbox and gateway session without replacing pairing state.

Recovery

  1. No reply: run ned doctor, then ned repair.
  2. Invalid/revoked token: revoke it in BotFather, run ned destroy --yes, create a new disposable bot, then run the installer again.
  3. Pairing expired: send hello for a fresh code and rerun ned pair <code>.

For revocation and direct absence checks, see Credentials, revocation, destroy, and troubleshooting.
