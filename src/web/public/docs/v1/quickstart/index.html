No Ego Dev · V1

Your private product partner on Telegram

One local command creates a private persistent Daytona Sandbox, connects ChatGPT through Hermes OAuth, and starts a verified Telegram gateway. Bot creation and owner approval are unavoidable Telegram actions; NED labels each one.

1. Install and start

i=$(mktemp) && curl -fsSL https://raw.githubusercontent.com/DataNavAI/no-ego-dev/248ae5966871da5d2a13305b9e69c48f964e7913/scripts/install.sh -o "$i" && { echo "8877f5ac61eeb7cb7586f5d7e83f37c146567c715dadc8a9f67a815f856cb42c  $i" | sha256sum -c - 2>/dev/null || echo "8877f5ac61eeb7cb7586f5d7e83f37c146567c715dadc8a9f67a815f856cb42c  $i" | shasum -a 256 -c -; } && bash "$i"; s=$?; rm -f "$i"; (exit "$s")

No sudo, Git, system Node.js, or system npm is required.

2. Follow the numbered Telegram actions

NED opens or links BotFather, validates the bot without printing its token, and shows only the verified username. Continue with the Telegram setup and owner-pairing steps.

3. Recover safely

  1. Run ned doctor.
  2. Run ned repair to restore the exact gateway without replacing the Sandbox.
  3. If a credential was exposed or revoked, follow credential revocation and destroy.
Never paste a Telegram bot token into argv, shell history, chat, logs, analytics, screenshots, source, fixtures, or a URL. NED accepts it only through hidden TTY input or its named macOS Keychain item.
