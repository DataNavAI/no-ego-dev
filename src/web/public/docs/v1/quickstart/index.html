No Ego Dev · V1

Your private product partner on Telegram

The installer prepares the Daytona-only CLI. ned create then creates one private, persistent Daytona Sandbox; connects ChatGPT with Hermes-native OAuth; validates a new Telegram bot; starts the pinned Hermes Telegram gateway; and verifies both inference and gateway readiness. The Sandbox is always-on by default (auto-stop=0). OpenRouter is not required or prompted.

1. Install NED

curl -fsSL https://raw.githubusercontent.com/DataNavAI/no-ego-dev/main/scripts/install.sh | bash

No sudo, Git, system Node.js, or system npm is required. This command executes the canonical installer in this repository; that installer verifies pinned private runtime and NED downloads before installation. It reads no cloud credentials and does not provision a workspace; after installation, run ned create yourself.

2. Create your Daytona Sandbox

ned create

NED securely reuses a compatible existing Hermes ChatGPT OAuth credential when available; otherwise it opens one fixed ChatGPT device-authorization page. It then guides you through the numbered BotFather actions and creates one private persistent always-on Sandbox.

3. Follow the numbered Telegram actions

NED opens or links BotFather, validates the bot without printing its token, and shows only the verified username. Continue with the Telegram setup and owner-pairing steps.

4. Recover safely

  1. Run ned doctor.
  2. Run ned repair to restore the exact gateway without replacing the Sandbox.
  3. If a credential was exposed or revoked, follow credential revocation and destroy.
Never paste a Telegram bot token into argv, shell history, chat, logs, analytics, screenshots, source, fixtures, or a URL. NED accepts it only through hidden TTY input or its named macOS Keychain item.
