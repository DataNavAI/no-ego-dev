NED CLI quickstart

Install the CLI

curl -fsSL https://raw.githubusercontent.com/DataNavAI/no-ego-dev/main/scripts/install.sh | bash
ned --help

Track project work

ned task init
ned goal create "Build login" --json
ned ready --json

Task data persists in a local shared SQLite database. Run ned com for the local project browser. Telemetry stays off until you enable it.
